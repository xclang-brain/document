# GitHub 移行説明資料

部門のバージョン管理を SVN から Git・GitHub に移行します。この資料では、移行の目的と進め方を説明します。移行後の操作手順は、別途運用手順書にまとめます。

## 移行の要点

| 項目 | 内容 |
| --- | --- |
| 移行内容 | バージョン管理を SVN から Git・GitHub に移行する |
| 目的 | レビューの記録やビルド・テストの自動化、AI 活用の幅の拡大 |
| 進め方 | コードから始め、V 字の下の工程から順に段階的に移行する |
| 開発者への依頼 | 第1段階（コードの移行）に向けて、Git・GitHub の基本操作を習得する |
| 時期 | （記載予定） |
