# GitHub 移行説明資料

部門のバージョン管理を SVN から Git・GitHub に移行します。この資料では、移行の目的と進め方を説明します。移行後の操作手順は、別途運用手順書にまとめます。

## 移行の要点

| 項目 | 内容 |
| --- | --- |
| 何をするか | バージョン管理を SVN から Git・GitHub に移行する |
| なぜ | レビューや CI を仕組みにでき、GitHub Copilot の機能を活用できるため |
| どう進めるか | コードから始め、V 字の下の工程から順に段階的に移行する |
| 開発者にお願いすること | 第1段階（コードの移行）に向けて、Git の基本操作を覚える |
| 時期 | （記載予定） |
